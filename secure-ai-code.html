Is my AI-generated code secure?

Short answer: it might work and still be unsafe. AI assistants optimize for code that runs, not for code that resists attackers. Here's what to look for.

The 5 most common problems

  • Hardcoded secrets: API keys pasted straight into source files.
  • Missing auth checks: endpoints that work for anyone, logged in or not.
  • Injection: user input glued into SQL queries or shell commands.
  • Over-open CORS and permissions: * everywhere because it made the error go away.
  • Client-side trust: prices, roles or limits checked only in the browser.

Quick self-check

  1. Search your repo for sk-, api_key, secret.
  2. For each API route ask: what happens if a logged-out user calls this?
  3. Look for string-built SQL queries.
  4. Ask your AI: "Act as a security reviewer. List every route without an auth check."

Why AI misses it

Your assistant only sees what you asked for. If you never said "make it secure", it usually won't add rate limits, auth or input validation on its own.
