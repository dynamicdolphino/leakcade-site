# Drip — Leakcade mascot

Original 16×16 pixel drip/ghost. Lime on dark, arcade 16-bit look.

| File | Pose |
|---|---|
| idle.svg | Hero, logo, default |
| scanning.svg | Loading / busy (animated scan line) |
| alarmed.svg | Critical findings |
| happy.svg | Score ≥ 80 / clean |
| sleeping.svg | 404 / empty |
| ../favicon.svg | Idle, favicon size |

Rebuild SVGs: `python3 mascot.py` from the repo root. Sheet: `previews/mascot-sheet.png`.
