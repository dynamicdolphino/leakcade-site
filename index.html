    FIX PROMPT
    In routes/user.ts, protect DELETE /api/delete-user with the existing session middleware. Only allow deleting the logged-in user's own account and return 403 otherwise. Add a test.

    FIX PROMPT
    Restrict CORS in server.ts to the production domain from an ALLOWED_ORIGIN env variable. Keep credentials enabled only for that origin.

Three mistakes AI coding tools make all the time.

Your assistant writes code that runs. It doesn't ask who else can call it.

Keys pasted into the code

We scan every file and the last 50 commits of git history, so a key you deleted three commits ago still shows up.

// src/config.js
export const openai = new OpenAI({
  apiKey: "sk-proj-************3fA9"  // leaked
})

Routes with no lock

Endpoints that work for anyone, logged in or not. We list each one with the file and line.

// routes/user.ts:44
router.delete("/api/delete-user", async (req, res) => {
  // no auth check
  await db.users.delete(req.query.id)
})

What a live-URL scan finds

Leaked keys in the frontend bundle, open Supabase tables, missing headers. Useful when the app is already online. Most vibe-coding scanners work this way.

What our repo check finds

Keys and bugs in the source and in git history, missing auth on routes, SQL built from strings. Useful before you ship, and for keys that never reached the browser.

We don't scan your live URL yet. If you only have a deployed app and no public repo, a URL scanner is the better fit today.

Questions

Does a clean report mean my app is secure?

No. Leakcade is an automated check and it can miss vulnerabilities. It is not a substitute for a professional security audit or penetration test. The report is provided as is, and you stay responsible for your code and for any changes you make. Where the law allows, our liability is limited to what you paid ($19). Details are in our Terms.

Is there a free scan?

Yes. Paste a public GitHub repo and your email. We run the open-source scanners only (no AI), then show the score, how many findings we found by severity, and one sample finding with the details redacted. Fix prompts and the full list are in the $19 report.

Do you run my code?

No. We never install, build or execute anything from your repo. Scanners and the AI only read the files, inside an isolated sandbox with no network.

Does my repo need to be public?

Yes, for now. We check with GitHub that it's public before we clone it. Private repos are planned.

What languages work?

JavaScript/TypeScript and Python get the deepest review. Most common web stacks work. On very large repos we focus on the files that matter most and tell you what was skipped.

Is this a security audit?

No. It's a fast, AI-assisted first pass that catches the mistakes vibe-coded apps make most often. If real money or personal data depend on your app, get a human audit too.

What if the AI is wrong?

It can be. Every finding names the file and line so you can check it in seconds, and scanner hits are kept separate from AI judgement.

Do you keep my code?

No. The clone is deleted as soon as your report is generated.

What's the difference between free and $19?

The free scan runs gitleaks, Semgrep, Bandit, OSV-Scanner, the package-name check and the auth-route check. The $19 report does the same, then adds an AI review and emails you every finding with a fix prompt as HTML and PDF. Free scans are capped at 20 MB and rate-limited.

What if the check fails?

If we can't run your check (for example the repo is private, empty or too big) or we don't deliver a report within 24 hours, you get a full refund automatically. Details in our refund policy.

Can I get a refund after I get my report?

Reports are delivered within an hour and can't be returned, so we don't offer refunds just for changing your mind. If your report is clearly broken or wrong, write to us and we'll review it.
